# U20 Spec — Branding, ownership & legal notice

## Goal
Give the interface the character of the original HTML tool and register it
as the user's creation: brand color scheme, ® ownership marks, year +
version, and a legal notice.

## Design decisions
1. **Color scheme from the original HTML** (`--accent #1F4FA3`,
   `--accent-h #183E85`, `--accent-lt #E8EEF8`): Tailwind v4 `@theme`
   brand palette (`brand-50/100/600/700`); all `indigo-*` classes swapped to
   `brand-*`; map alignment color `--clr-alignment` follows.
2. **Header** becomes a deep-blue brand bar: "Microtunnel Design Tool®" +
   "Branako K. Primm, PE · © 2026 · v1.0.0" + module subtitle + Help button.
3. **Footer bar**: "Microtunnel Design Tool® v1.0.0 — a creation of
   Branako K. Primm, PE · © 2026. All rights reserved." + "Legal notice"
   button that opens the Help modal.
4. **Help modal** gains a "Legal notice" section (suggested wording —
   proprietary creation, screening aid, unsealed outputs, no warranty,
   no unauthorized copying).
5. **HTML report footer** carries "Generated by Microtunnel Design Tool®
   v1.0.0 — © 2026 Branako K. Primm, PE. All rights reserved."

## Out of scope
- Actual USPTO trademark registration (a legal process outside the tool);
  the interface carries the ® notice and copyright claim as requested.

- [ ] Brand palette applied across the interface; header/footer branded
- [ ] Legal notice in Help modal; report footer branded
- [ ] Tests green, `tsc` clean, ESLint clean, production build succeeds
- [ ] progress-tracker.md updated (U20 done)
